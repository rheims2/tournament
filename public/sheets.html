Which sheets should this page show?

One per line: Name | link. The name is what the tab is labelled; leave it off and you get “Sheet 1”, “Sheet 2”, and so on.

Each sheet must be a real Google Sheet shared as “Anyone with the link — Viewer”. For a sheet with several tabs, add one line per tab and keep the #gid=… that Google puts in the URL when that tab is open.
